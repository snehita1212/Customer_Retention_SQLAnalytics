# Project Overview

## Background
Customer retention is an important indicator of long-term profitability for any subscription-based business. More than acquiring new customers, retaining existing customers delivers higher lifetime value and stronger business sustainability.
This project replicates a customer analytics engagement for a streaming platform called **NovaStream**. Using subscription, engagement, billing, support, and demographic data, the project aims to identify key churn drivers, understand behavioural patterns, and make retention strategies.

## Business Challenge
Customer churn impacts recurring revenue, customer lifetime value, and overall business growth. NovaStream seeks to understand the following:
* Which customers are most likely to churn?
* What factors contribute to churn status?
* How customer engagement affects retention?
* Which customer segments generate the highest business value?
* What actions can be taken to improve retention rates?

## Project Objectives
* Build a structured analytics environment using PostgreSQL (Neon).
* Transform raw customer data into normalized data model.
* Develop a customer intelligence layer for business analysis.
* Create a weighted churn risk scoring model.
* Analyze retention patterns across customer segments.
* Build interactive Power BI dashboard for stakeholders.
* Generate business recommendations on above observations.

## Dataset Overview
The dataset contains 1,000 customer records representing a streaming platform subscriber base.
Key attributes:
* Subscription plan
* Subscription length
* Customer satisfaction score
* Daily watch time
* Engagement score
* Device usage
* Genre preference
* Payment status
* Support queries logged
* Demographic area
* Churn status

## Deliverables
This project produced the following:
* PostgreSQL analytics database
* Normalized relational data model
* Customer intelligence mart
* Churn risk scoring model
* Business intelligence dashboards
* Customer retention insights
* Strategic recommendations

## Expected Business Impact
The analytical framework developed in this project can help subscription businesses in the following ways:
* Identify high-risk customers earlier
* Improve retention strategies
* Optimize onboarding initiatives
* Increase customer lifetime value
* Support data-driven business decisions
The project combines SQL analytics with business intelligence reporting to demonstrate how customer data can be transformed into actionable business insights.
