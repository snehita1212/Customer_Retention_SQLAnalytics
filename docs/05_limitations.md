# Project Limitations

This project was carried out using a simulated streaming-platform dataset intended for analytics and business intelligence practice.<br>

The analysis identifies patterns and relationships observed within the dataset; however, these findings should not be understood as validated relationships or true representatives of real-world Netflix customer behavior.<br>

The primary objective of the project is to demonstrate end-to-end analytics capabilities, like SQL analysis, churn-risk assessment, dashboard development, and business recommendations generation.<br>

Several patterns such as genre-specific churn differences, age-related engagement anomalies, and regional retention variations, reflect characteristics of the simulated dataset rather than **actual** customer behavior.<br>

Further work using real operational data is required to validate these findings and establish relationships.<br>
